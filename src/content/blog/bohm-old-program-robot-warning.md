# 長篇編輯：涵蓋 2020-07-29 至 2026-07-29（共 2191 天）
接下來你要聽到的，是物理學大師 David Bohm 親口說的話。沒有廢話，直接聽他的警告。

他是大衛·玻姆，理論物理學大師，被愛因斯坦視為「精神之子」。他曾師從奧本海默，提出量子位能與內隱秩序，用科學證實宇宙是一個不可分割的整體。他最知名的就是發現了「玻姆-阿哈諾夫效應」，準確預言了量子糾纏的深遠影響。在 1949 年，他因為拒絕出賣同事而遭到政治迫害，被迫流亡。今天，我們整理了他晚年對人類文明最深層的警告，聽完你可能會對世界有完全不同的看法。

**我們都是被設定好的機器人？**
玻姆說：「發生的一切，都記錄在大腦中。這像一盤磁帶，像電腦程式。讓我們用特定方式，去行動和思考。人類的問題，起源於思想本身，起源於意識本身。我們像失去連結的，獨立機器人。在深穴裡困惑，互相爭鬥，互相傷害。文明累積了傳統，腦細胞填滿了程式，人們變得無法做，任何新的事情，於是文明就死去了。」他指出，國家之間不斷交戰，人們對奉承的追求、對侮辱的憤怒，能持續數百年，這一切都記錄在大腦的程式中。一切都被劃分為國家和宗教，表現得好像獨立，但事實並非如此，這是虛假的幻覺。

**比核彈更危險的「蝗蟲」危機**
玻姆警告：「人們必須放棄，否則我們無法生存。我們現在擁有的核子武器，足以將全世界人口殺死不知道多少次。我們正處於一場與時間，最危險的賽跑。」他年輕時曾深信貧窮是人類主要問題，但後來發現科學無法解決貧窮。他觀察到：「現在的人們，盲目致力於，所謂的經濟增長。如果五十億人口，都想過上歐美的生活標準，我們就像是一群，降落在行星上的，蝗蟲。會把一切，啃食殆盡。整個體系會比以往，崩潰得更快。地球其實，就是一個家園。每個人就是每個人。金錢如何花費，取決於我們的，意識。」

**量子大師的「跳石法則」找回安全感**
玻姆分享了一個童年體悟：「我大約十二歲時，要穿過一條，流速極快的小溪。那裡有很多，很小的小石頭。我當時非常焦慮。我突然意識到，你必須從一塊石頭，跳到另一塊石頭，中間不能停下來。你必須處於流動的狀態。安全感，存在於運動之中，而非固定的位置。」他建議，當恐懼發生時，不要試圖壓制它，也不要合理化它。你必須與之待在一起，像觀察外部物體，觀察你內在的程式。它最終會自然坍塌。

**30人就能釋放巨大能量拯救世界？**
玻姆認為，作為普通人，你必須開始覺察你的程序，透過你與他人的關係，來反射出你的程序。在面對不同觀點時，你必須懸掛你的意見，去觀察它，而不是去為它辯護。他強調：「普通人能做的，最重要的一件事，就是組成小組，進行真正的對話。如果三十人，能真正放下，自我的防衛，用同一個大腦，一起思考。這會釋放出，巨大的能量。能把趨勢，轉向安全的方向。」
